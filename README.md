MAC 연산에 대해 학습하고, 엑스자와 십자 패턴을 컴퓨터가 인지할 수 있도록 계산기를 만듦

## 실행 방법
1. 같은 디렉토리에 main.py 와 data.json 설치
2. 해당 디렉토리에서 터미널을 통해 `python main.py` 입력 
3. 모드 선정(1 또는 2 입력)

<br>

### 모드1 
- 필터 2개와 판정할 패턴 1개 입력 
- 결과 확인 
<br>

### 모드2 
- 데이터 로드
- 결과 확인

<br>

## 프로젝트 구조
### InputData 클래스
- 데이터를 입력 받거나, json 파일로부터 로드해올 수 있다.
- 입력받은 데이터를 리스트에 저장한다.
- 라벨이 존재할 경우, 정규화를 진행한다.
### Analyze 클래스
- 저장한 데이터를 MAC 연산을 통해 계산한다.
### Evaluate 클래스
- 연산 결과를 분석하고, 출력한다.
